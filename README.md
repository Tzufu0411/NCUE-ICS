# 彰師大課表轉換

將彰師大選課系統匯出的「學生課表」PDF，自動轉換成可使用的 `.ics` 行事曆檔案或 Excel 課表。

## 功能

* 📄 上傳學生課表 PDF
* 📅 自動解析課程、時間、教室、教師
* ✏️ 編輯、新增、刪除課程
* 🏫 自動轉換教室名稱
* 🗓️ 設定學期開始與結束日期
* 📆 匯出可使用的 `.ics` 行事曆
* 📊 匯出 `.xlsx` Excel 課表
* 🔒 全程於瀏覽器本機處理，不上傳課表資料

## 操作流程

1. 從彰師大選課系統下載「學生課表」PDF。
2. 將 PDF 拖曳或上傳至本工具。
3. 確認自動解析的課程資料。
4. 需要時編輯、新增或刪除課程。
5. 設定學期開始與結束日期。
6. 點選 **匯出 ICS**，取得 `.ics` 行事曆檔案。
7. 將 `.ics` 匯入 Google 日曆、Apple 行事曆等支援 ICS 的行事曆服務。
